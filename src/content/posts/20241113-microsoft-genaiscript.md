title: "Microsoft GenAIScript: A Scripting Framework for LLMs"
date: 2024-11-13T08:00:00-06:00
---

I came across this interesting project from Microsoft called [GenAIScript](https://microsoft.github.io/genaiscript/). It's a framework for creating LLM-based programs, looking sort of like a jQuery for LLMs—it even uses the `$` symbol.

It can work with various models, including ones you can run locally, but appears to mostly target OpenAI's APIs. They have a lot of practical examples in their documentation, including [one for creating a pull request description](https://microsoft.github.io/genaiscript/samples/prd/) automatically.
