title: "MonkeysPaw: A Prompt-Driven Web Framework"
date: 2025-04-16T08:00:00-05:00
---

I came across this [interesting little experimental web framework called MonkeysPaw](https://worksonmymachine.substack.com/p/introducing-monkeyspaw-a-prompt-driven). The concept is that rather than writing code, you describe what you want in text via Markdown. Each Markdown file represents a page, and you can link to other pages just by saying you want to link to the "Get Started" page, etc.

While just an experiment, I think it's an eye-opening look at how systems and how they are built will likely start to change. It's also fun to play around with.
