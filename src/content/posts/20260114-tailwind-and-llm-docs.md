---
title: "Tailwind CSS and the LLM Documentation Dilemma"
date: 2026-01-14T08:00:00-06:00
---

I saw [this GitHub PR comment](https://github.com/tailwindlabs/tailwindcss.com/pull/2388#issuecomment-3717222957) from Adam Wathan, CEO of Tailwind Labs and creator of the Tailwind CSS framework. The PR proposed adding an endpoint for text-only documentation optimized for LLMs.

Interestingly, Tailwind Labs has relied heavily on developers visiting their documentation to learn about paid services from the company. Because developers are increasingly querying documentation through LLMs rather than visiting the site directly, the company is struggling to stay afloat even though the framework continues to grow in popularity.

Clearly that's a problem with their business model that they'll need to adapt to, but it's also fascinating to see the unexpected ways LLMs are altering developer behavior and impacting businesses built around open source.
