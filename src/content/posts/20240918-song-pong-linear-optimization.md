I came across [this fun Substack post about using "linear optimization" to have a game of pong match random songs](https://victortao.substack.com/p/song-pong).

The post describes identifying the constraints for the solver to work within and then using a linear problem solver called CVXPY to do the work of solving based on those constraints. Extremely cool results, which you can see in the video clips. I hadn't heard of these linear problem solvers before and it seems like something really interesting to play with.
