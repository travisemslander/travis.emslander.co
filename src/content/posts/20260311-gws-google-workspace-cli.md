title: "gws: An Unofficial Google Workspace CLI for AI Agents"
date: 2026-03-11T08:15:00-05:00
---

I recently came across [gws](https://github.com/googleworkspace/cli), an open source CLI tool for Google Workspace (covering Gmail, Drive, Sheets, Docs, and more).

While it's an unofficial project not affiliated with Google—meaning you'll want to exercise proper caution with permissions—its primary aim seems to be giving LLM agents a straightforward command-line interface into Google Workspace services. It's an interesting approach to agentic tool use, definitely worth experimenting with (using a test Google account, of course).
