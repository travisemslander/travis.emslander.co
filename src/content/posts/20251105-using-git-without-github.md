---
title: "Using Git Without GitHub"
date: 2025-11-05T08:00:00-06:00
---

GitHub has become so synonymous with version control that it's easy to forget Git itself is completely decentralized.

While hosted platforms like GitHub are great for collaboration and open-source distribution, if you simply want version control and remote backups for personal machines, [it's surprisingly simple to manage Git without GitHub or third-party servers](https://maurycyz.com/misc/easy_git/). If you have a Git repository on one machine with SSH access, you can clone and push directly over an `ssh://` URL without any special server software required.
