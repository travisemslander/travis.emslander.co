---
title: "Google Introduces Code Wiki"
date: 2025-12-17T08:00:00-06:00
---

[Google introduced "Code Wiki"](https://developers.googleblog.com/en/introducing-code-wiki-accelerating-your-code-understanding/), which uses AI to create a wiki of your codebase.

Currently it's limited to working with open source public repositories, so if you maintain open source code you can give it a spin. They plan to release a Gemini CLI extension to enable creating private wikis for closed-source private repositories, which will be an interesting tool to keep an eye on for internal codebases.
