Sprite Fusion published a fascinating writeup on [using AI (specifically GPT-6 Astra) to create playable Game Boy Advance ROMs](https://www.spritefusion.com/blog/making-a-game-boy-advance-game-with-gpt-6-astra).

The author guided the model to generate and compile native C code targeting the GBA architecture, then ran the resulting ROM files in an emulator. One detail left unmentioned was how they flashed and ran the build on physical Game Boy Advance hardware for their hero photo—flashing homebrew AI-generated ROMs onto an actual flashcart like an EverDrive would be the ultimate end-to-end retro test.
