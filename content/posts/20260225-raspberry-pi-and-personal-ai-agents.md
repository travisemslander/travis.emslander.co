[Raspberry Pi's stock price surged 30%](https://finance.yahoo.com/news/british-computer-maker-soars-ai-141836041.html?guccounter=1&guce_referrer=aHR0cHM6Ly9vbW5pdm9yZS5lbXNsYW5kZXIuY28v&guce_referrer_sig=AQAAAKvBg-C4kJYIhmmayfoKL64MlwTxLpapEZvOG2GwDYCfO0O8975e67BVHO9iJiW-FHOVS3bmcayfSHUzOu_6PQb-ktdv8Xk0CxF51TArGas99VjRfde0XeysXT3kfN7VwZ8jfF5N5Dp-895Sz9CKLLjJ2mU7jGlz-2YHYbG-b_fV) recently, with many attributing the run to the popularity of using these single-board computers to host personal AI agents like OpenClaw (or lighter alternatives like picoclaw).

While personal agents are exciting to experiment with, it's worth reiterating a critical safety rule: don't run these directly on your main workstation with unrestricted access, and never give them API keys or credentials to sensitive work resources. If that sounds overly cautious, consider this cautionary tale where an agent was given access it shouldn't have had and [ended up deleting all of the user's emails](https://x.com/summeryue0/status/2025836517831405980)—and the user was an AI safety researcher at Meta!
